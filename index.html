Martin Schäf

Principal Applied Scientist, AWS

I build analysis and verification systems that turn program behavior into evidence people and machines can act on.

At Amazon Web Services I apply techniques from formal verification and program analysis to cloud billing contracts. Previously at AWS, I worked on AI and security developer tools, including Kiro, CodeWhisperer, and CodeGuru.

Research Themes

✓

Program Analysis and Verification

Developing static analyses that find bugs and prove their absence, from CHC-based heap reasoning and typestate verification to scalable security and compliance analysis.

☉

Fault Localization and Diagnosis

Using proofs and executions to isolate faulty statements, compress error traces into explanations, and turn solver artifacts into diagnoses developers can act on.

⇄

Interactive Reasoning Systems

Designing systems where people, language models, and symbolic analyzers work together to formalize knowledge, identify missing facts, check conclusions, and return understandable evidence.
